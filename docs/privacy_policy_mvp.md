# ホウレンチェック プライバシーポリシー MVP

## 利用目的

ホウレンチェックは、報告タイミングの通知、報告文作成支援、報連相支援、一般就労移行および定着支援のために必要な情報を扱う。

本サービスは、診断支援、医療情報管理、障害情報管理、勤怠管理、給与管理、人事評価を目的としない。

## 取得する情報

- ユーザーの氏名、メールアドレス、ロール、アカウントモード
- 通知スケジュール、通知イベント、通知ログ
- 報告イベント、報告本文、送信先、送信履歴
- 相談スレッド、返信、確認履歴
- 担当者紐づけ、モード切り替え、一般就労移行に関する申請および監査ログ

## センシティブ情報

報告本文および相談内容には、健康情報、障害情報、診断名、家庭事情など、業務報告に不要なセンシティブ情報を入力しないことを原則とする。

## 保存期間

- 通知モードの `notificationEvents`: 30日
- `notificationLogs`: 30日
- `reports` と `reportDeliveries`: 180日を目安に削除または匿名化
- 退会済み `users`: 180日を目安に匿名化
- `auditLogs`: 説明責任と不正防止のため保存

## 退会

退会時は `users.active=false` にし、Firebase Auth を無効化する。退会後は新規 `reportEvents` / `notificationEvents` を生成しない。
